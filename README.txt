Smart CLI tool for much better and comfortable experience with Noita. 
Using this tool undermines the true meaning of permadeath in this game.

Enables save slot folder(s) backuping into configured output folder from the configured Nolla_Games_Noita path and even much more. 
Just backup your run, load it when you need and you can also immediately start the game directly inside the console by simple command.

Features backuping, loading, removing and renaming backups, listing backups or saves, clearing saves (keeping information about already played intro), backup name or save number pruning with settable max version and purging, and also quick game execution (by path on Windows, by command on Unix-like or other systems).

No external libraries or packages needed.
Supports multiple save slot numbers, which can be created using mods (e.g. Save Slots Enabler mod) or third-party applications.

Important note: Always quit & save your game before making a backup, the current Noita save slot folder is not updating while in mid-game!
